# Security Policy

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/Trifocals3537/Tessarr/security/advisories/new) to send a private report to the repository maintainers.

Please keep exploit details and sensitive information out of public issues and pull requests while a report is being investigated.

Include the following where possible:

- The Tessarr version, or the branch and commit for a development build.
- The operating system and deployment method, such as Docker or a native binary.
- Clear reproduction steps and a small example that demonstrates the issue.
- The expected behavior, actual behavior, and potential security impact.
- Relevant logs or screenshots with API keys, passwords, tokens, and personal information removed.

Test only systems you own or have permission to assess. Coordinate public disclosure with the maintainers so a fix or mitigation can be shared with users.

## Versions

Please check whether the issue occurs in the latest stable release. If it affects an older release or a beta/development build, include that information in the report.

## Other issues

Use [GitHub Issues](https://github.com/Trifocals3537/Tessarr/issues) for ordinary bug reports and feature requests that do not disclose a security vulnerability.
